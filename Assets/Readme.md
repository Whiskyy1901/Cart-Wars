# Cart Wars

Cart Wars is a singleplayer movement game built in Unity, 
where you play as a delivery guy racing to complete orders. 
It started as a multiplayer supermarket competition for up to 4 players, 
and this version scales that idea down: the same physics-driven world and customers, 
now focused on getting the goods where they need to go as fast and as stylishly as you can.

Status: Actively in development.

## Implemented Systems

1. Active ragdolls for NPCs/customers
2. Interaction system (order/buy menu, dialogue menu)
3. Grappling hook, used to traverse the environment quickly

## Planned Features

1. Order system (accept an order, pick up the goods, deliver to the customer)
2. Customer NPCs who place and receive orders
3. Earnings and rewards for completed orders
4. Delivery timers and performance ratings
5. Expanded map with multiple delivery routes
6. Progression and win condition

## How to Run

1. Download the latest version from the [Cart Wars Itch.io page](https://whiskyyyy.itch.io/cart-wars)
2. Extract the downloaded zip file
3. Run `CartWars.exe`

## Controls

| Action   | Input           |
|----------|-----------------|
| Move     | WASD            |
| Look     | Mouse           |
| Interact | Hold E          |
| Pick up  | F               |
| Grapple  | Hold Left Click |
